# Fuel Sales Manager

Criar um aplicativo para android que controla as vendas de um posto de combustiveis.

Permitir o usuario configurar cores dos tanques, nome dos combustíveis e capacidade dos tanques.

O usuário deve informar as medidas de todos os tanque no inicio do turno 1 de cada dia. No dia seguinte, o usuario deve informar as vendas do turnos.

Todas as medidas inseridas pelo usuario devem ter um botão de editar caso seja necessario editar a medida.

Criar um menu Escala e permitir inserir a quantidade de turnos, nome e horario de cada frentistas. Botao editar necessario para correções.  Permitir marcar as folgas dos funcionarios e destacar a folgas com outra cor.
